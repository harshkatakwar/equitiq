# ResearchOS — Data Sources

## Data Mode Configuration

Set via `DATA_MODE` environment variable:

| Mode | Value | Description |
|------|-------|-------------|
| Demo | `demo` | Synthetic data, no external dependencies |
| Official | `official` | Legally permitted public sources |
| Licensed | `licensed` | Commercial data feeds |

## Demo Mode Sources

All synthetic. Generated by seed scripts. Every document/value marked:
> "Demo content — not an exchange filing"

| Dataset | Source | Companies |
|---------|--------|-----------|
| Company master | Seed script | 10 companies across 10 sectors |
| EOD prices | Generated time series | 2 years of synthetic prices |
| Financial statements | Generated P&L, BS, CF | 8 quarters + 2 annual periods |
| Announcements | Synthetic announcements | ~50 per company |
| Concall events | Synthetic schedule | 8 per company |
| Transcripts | Synthetic Q&A | 4 per company |
| Annual reports | Synthetic summaries | 2 per company |
| Shareholding | Synthetic patterns | 8 quarters per company |

## Official Mode Sources

| Source | Dataset | Access Method | Rate Limits | Terms |
|--------|---------|---------------|-------------|-------|
| NSE India | Company master, EOD prices, corporate actions | Public website/API | Respect robots.txt | No commercial redistribution without licence |
| BSE India | Company master, announcements | Public website/API | Respect robots.txt | Display restrictions apply |
| Company IR sites | Annual reports, investor presentations | Direct download | Per-site limits | Fair use for analysis |
| MCA/RoC | Company filings | Public search | Rate limited | Government data |
| RBI | Macro indicators | Public API | Minimal | Open data |

### Official Mode Rules
- Never bypass CAPTCHAs or access controls
- Respect `robots.txt` and `Crawl-delay`
- Cache responses to minimize requests
- Do not redistribute raw data
- Attribution required on display

## Licensed Mode Provider Interfaces

```python
class MarketDataProvider:
    async def get_security_master(exchange, as_of_date)
    async def get_eod_prices(security_id, from_date, to_date)
    async def get_corporate_actions(security_id, from_date, to_date)

class CorporateDataProvider:
    async def discover_filings(company_id, filing_types, from_date)
    async def fetch_document(filing_id)
    async def get_announcements(company_id, from_date, categories)
    async def get_financial_results(company_id, periods)
    async def get_shareholding_patterns(company_id, quarters)

class ConcallProvider:
    async def get_events(company_id, from_date, to_date)
    async def get_recordings(event_id)
    async def get_transcripts(event_id)
```
